Gym-Duckietown (ai-vnv fork)
============================

Python + OpenGL (Pyglet) simulator environments for **Gym**, aligned with upstream **Duckietown** ``daffy`` with lab-specific patches (NumPy 1.x, Pyglet 1.x, macOS Cocoa, procedural tile textures, multiview rendering).
